# Research Work Samples

I am Taenyoung Lee, a Ph.D. student in Statistics at the University of Connecticut. This repository collects selected work in computational statistics, numerical optimization, and statistical programming in R and Python.

| Project | Language | What I worked on |
| --- | --- | --- |
| [Gangneung Rainfall Analysis](01-Rainfall-Analysis/) | R | Prepared monthly rainfall observations, compared seasonal time-series models, and used a Gamma regression to examine unusually wet or dry months. |
| [Robust Margin-Based Classification](02-Robust-Classification/) | R | Implemented margin-based classifiers with shifted losses and designed simulations to compare them under asymmetric training-label noise. |
| [Code Similarity Analysis](03-Code-Similarity/) | Python | Implemented pairwise comparisons of R scripts using text matching and cosine similarity of BERT embeddings. |

Each project includes source code, a description of the methods, and instructions for running it.
